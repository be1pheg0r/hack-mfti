# IT Purple Hack 2026 | RnD Свердловской синагоги

## Обзор

В этом репозитории собраны материалы команды RnD Свердловской синагоги для хакатона IT Purple Hack 2026.

Репозиторий разделён на общую часть и отдельные реализации кейсов. Полные реализации решений лежат в отдельных ветках по каждому кейсу.

## Структура репозитория

В `main`-ветке находятся:

- описание кейсов;
- данные для кейсов Сбера и Авито;
- общие утилиты и вспомогательные файлы.
- baseline для кейса Сбера

Полные решения вынесены в отдельные ветки:

- `case/avito` — решение кейса Avito;
- `case/sber` — решение кейса Сбер;
- `case/igs` — решение кейса Igs.

## Кейсы

### Avito

Решение кейса Avito построено как pipeline с LLM + RAG, где для принятия решений используются модели Mistral через API.  
Подробное описание и запуск решения находятся в соответствующей ветке.

### Сбер

Для кейса Сбер была построена система определения галлюцинаций в ответах модели на основе набора uncertainty features, internal scalars, probe-векторов и дополнительных признаков.  
Подробности реализации также доступны в отдельной ветке.

### Мини-гайд по страхованию

Для третьего кейса был разработан интерактивный мини-урок по страхованию для подростков. Решение выполнено в формате веб-приложения с пошаговым сценарием, маскотом, геймификацией и мгновенной обратной связью.

## Примечание

Для просмотра полной реализации конкретного кейса нужно переключиться на соответствующую ветку.
