IT Purple Hack 2026 | Мини-гайд по страхованию | RnD Свердловской синагоги

Обзор
Кейс был направлен на создание короткого, дружелюбного и понятного формата обучения страхованию для подростков.

Страхование часто воспринимается как что-то «взрослое», сложное и скучное. Из-за этого полезную защиту либо игнорируют, либо выбирают неподходящий вариант наугад.  
Наша цель — объяснить базовые принципы страхования через интерактивный сценарий с приколами, геймификацией и мгновенной обратной связью.

Решение
Мы сделали веб-приложение в формате мини-урока.

Пользователь проходит последовательность шагов: история, вопрос, реакция, следующий шаг. Каждый шаг — это либо информационный блок, либо проверочный вопрос. После ответа пользователь сразу получает реакцию маскота, что делает обучение более живым и вовлекающим.

В приложении есть персонаж-маскот, который сопровождает пользователя по всему сценарию. Также реализованы:
- прогресс урока в виде пути до финала;
- вертикальный индикатор ошибок;
- модалка при превышении лимита неправильных ответов;
- финальная сцена с поздравлением и возможностью перезапуска.

В начале пользователя помогает начать ежиха, а в конце появляются Сон Ки Хун и Кан Сэ Бёк, чтобы поздравить с завершением урока и предложить пройти его заново.

Технологии
React + TypeScript + Yarn.

Деплой выполнен через Firebase.
