# IT Purple Hack 2026 | Мини-гайд по страхованию | RnD Свердловской синагоги

## Обзор

Кейс был направлен на создание короткого, дружелюбного и понятного формата обучения страхованию для подростков.

Страхование часто воспринимается как что-то «взрослое», сложное и скучное. Из-за этого полезную защиту либо игнорируют, либо выбирают неподходящий вариант наугад.  
Наша задача заключалась в том, чтобы объяснить базовые принципы страхования через интерактивный сценарий с элементами геймификации, юмора и мгновенной обратной связи.

## Решение

Мы разработали веб-приложение в формате мини-урока.

Пользователь проходит последовательность шагов: история, вопрос, реакция, следующий шаг. Каждый шаг представляет собой либо информационный блок, либо проверочный вопрос. После ответа пользователь сразу получает реакцию маскота, что делает обучение более живым и вовлекающим.

В приложении реализованы:

- прогресс урока в виде пути до финала;
- вертикальный индикатор ошибок;
- модальное окно при превышении лимита неправильных ответов;
- финальная сцена с поздравлением и возможностью перезапуска.

В начале пользователя сопровождает ежиха-маскот, а в конце появляются Сон Ки Хун и Кан Сэ Бёк, поздравляя с завершением урока.
